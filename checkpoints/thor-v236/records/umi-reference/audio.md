# HakiOS (Xiaomi Mi 10 "umi", SM8250, XNU 8796) audio reference notes for Thor

Read-only study of `reference-umi/hakios-xnu-kernel-umi-fixes`, 2026-11-25. Aliases: `dev/` = `devices/xiaomi-mi-10/overlays/xnu/files/bsd/dev/`, `sys/` = `.../bsd/sys/`, `drv/` = `drivers/audio/`, `ul/` = `userland/src/`, `build.sh` = `devices/xiaomi-mi-10/overlays/userland/build.sh`, `VOICE` = `devices/xiaomi-mi-10/VOICE-CS-umi.md`. As read unless tagged **[inferred]**.

## Summary
- Layers: a hand-written ADSP loader plus SMP2P/GLINK/QRTR/APR stack in the kernel (no IOKit); codec and amp bring-up by MMIO and bit-banged I2C; a user-space AudioServerPlugIn (`HakiosAudio.driver`) in mediaserverd on two BSD devices, `/dev/hakios-audio` and `/dev/hakios-mic`.
- Protocol: **APR only** (AFE 4, ASM 7, ADM 8; voice MVM 9, CVS 10, CVP 11) on GLINK channel `apr_audio_svc`. GPR/AudioReach: not found.
- Docs describe speaker playback and microphone as working. **Voice call audio is implemented but not demonstrated** ("neither a connected CS call nor call audio is demonstrated", VOICE:3; acceptance "待真机", VOICE:394). The cited device log is not in the checkout; I saw no acoustic proof for any path.
- Caveat for Thor: Thor already has `PongPower/ShengGpr.c` and `ShengAudioReach.c` (GPR, PARAM ids `0x080010xx`; heads only read), and **[inferred]** SM8475 ADSP firmware speaks GPR/AudioReach, not APR. Portable: CS35L41 register work, HAL plug-in, SMMU/period-ring pattern, sequencing concept. Not portable: opcodes, addresses.

## Boot arguments
`boot.args`: `adsp=1 adsp_umi=1 sound=4 umi_mic=4` (+ `haptic=5 battery=1`).
- `adsp=1`: all 11 steps on a thread after root mount, DSP kept up; gated on `pe_arm_get_soc_base_phys()==0x400000` (dev/hakios.adsp.c:3437-3457). `adsp_umi=1`: carve-out `0x8bb00000`+`0x2500000` instead of `0x86700000`+`0x4000000` (:988-996, :3431-3435) and the UMI sound profile (dev/hakios.sound.c:1715-1727).
- `sound=1..4`: port only / + ASM/ADM stream and tone / + amps (UMI: capped 1 s tone, :1632-1637) / what iOS writes (:19-45). `sound_below` in eighths of a dB (UMI default 240; 96 if both amps calibrated, :1646-1650); `sound_gain` forced to 0 (:1717-1719). `umi_amp_probe=1..5` (dev/hakios.speaker.c:1231-1238).
- `umi_mic=1..4`: votes and clocks only / codec enumerates / 10 s capture test / `/dev/hakios-mic` on demand (dev/umi_mic.c:7-12); legacy `mic=` ignored (:1719-1720). `rec_sound=N`, `rec_sound_fed=1`, `rec_sound_mic=1`: in-memory recordings (drv/hakios.audio.c:10-22).

## ADSP boot
- Not a remoteproc driver: a copy of the Wi-Fi DSP loader (hakios.adsp.c:18-30) that shares three locks with `hakios.wifi.c` (:110-113) plus `hakios_smmu_lock`. The SMMU serves only the PCM stream.
- `adsp.mdt` + `adsp.bNN` parsed by hand (ELF32 phdrs at `52+32*i`, relocatable bit 27), read from `/fw/` or the small image (:1005-1245).
- Steps (:36-53): open AOP QMP mailbox `0x0c300000` (:600-740) → SCM PAS init image, mem setup (pas id 1) (:1263-1312, :1469-1493) → copy segments into the carve-out (`ml_io_map_unmappable(..., VM_WIMG_WCOMB)`), read back (:1517-1574) → allocate SMEM items 429 (our SMP2P) and 479 (GLINK queue, 16 KiB) under spinlock `0x01f43000` (:1582-1807) → rails `lcx.lvl`/`lmx.lvl` = 384 via RPMh TCS 0 at `0x18220000+0xd00`, addresses from cmd-db `0x80860000` (:893-960) → AOP text `{class: image, res: load_state, name: adsp, val: on}` → SCM auth and reset (:1845-1857) → watch "slave-kernel": bit 1 ready, bit 2 power handover (rails 0), bit 0 fatal, last words in SMEM item 423 (:519-524, :1874-1917) → GLINK opens `IPCRTR`, `apr_audio_svc`, `PMIC_RTR_ADSP_APPS` (:2022-2029) → QRTR hello (:2518-2531) → APR `AVCS_CMD_ADSP_EVENT_GET_STATE 0x1290c` until `0x1290d` words[0]==1 (:3273-3317) → `hakios_sound_dsp_up()`, `hakios_mic_dsp_up()` (:3411-3416).
- SCM: `x0 = 0x42000200|cmd`, cmds 1 init image, 2 mem setup(addr,size), 5 auth and reset, 6 shutdown; `x6` session; retry while `x0==1` (:1263-1312).
- SMEM `0x80900000` (2 MiB), host 0 ↔ DSP 2; IPCC `0x04080000`, client 3, signal 0 GLINK, 2 SMP2P (:291-294, :619-630). A link thread polls every 1 ms (:3060-3112). Shutdown: stop bit → PAS shutdown → AOP `val: off` → rails 0 (:1411-1439).

## APR/GPR sequences
Header 20 B: `u16 field=(2<<8)|(5<<4)`, `u16 size`, `from_service`, `from_domain=5`, `from_port`, `to_service`, `to_domain=4`, `to_port`, `u32 token`, `u32 opcode` (:2641-2659). `hakios_adsp_apr(svc, port, token, opcode, payload, len, wait_ms, answer)` (:2741-2805); `APR_BASIC_RSP_RESULT 0x110e8` = {opcode, status}; `wait_ms=0` = unwaited.

(a) Speaker, in order (dev/hakios.sound.c):
1. AFE `AFE_SVC_CMD_SET_PARAM 0x100f3` {size,0,0; module `0x1028f`, param `0x10290`; {1, clk `0x104`, 1.536 MHz, attr 1, 0, on}} (:453-463).
2. AFE `AFE_PORT_CMD_SET_PARAM_V2 0x100ef` port `0x1004`: module `0x1020c`, param `0x1020d`, `{1, bits 16, channel_mode 2, stereo 1, ws_source 1, 48000, 0, 0}` (:486-493).
3. AFE `AFE_PORT_CMD_DEVICE_START 0x100e5` {`0x1004`, 0} (:499-500).
4. ASM port 0 `SHARED_MEM_MAP_REGIONS 0x10d92` {pool 3, regions 1, 0, addr lo, hi, 32768} → `0x10d93` words[0] = handle (:1000-1041).
5. ADM port `0x1004` `DEVICE_OPEN_V5 0x10326` {flags 0, mode 1, ep1 `0x1004`, ep2 `0xffff`, topology `0x10312`, ch 2, bits 24, 48000, map {1,2}} → `0x10329` {status, copp} (:1006-1053).
6. ASM port `0x101` (session 1, stream 1) `STREAM_CMD_OPEN_WRITE_V3 0x10db3` {0, 0, bits 16, topology `0x10c68`, fmt `0x10da5`} (:1019-1023, :1054-1057).
7. ADM port 0 `MATRIX_MAP_ROUTINGS_V5 0x10325` {matrix 0, sessions 1, session 1, copps 1, {copp}} (:1014-1018).
8. ASM `DATA_CMD_MEDIA_FMT_UPDATE_V2 0x10d98` {size 20, ch 2, bits 16, 48000, signed 1, map {1,2}}; `SESSION_CMD_RUN_V2 0x10daa` {0,0,0} (:1024-1031, :1061-1063).
9. Per period ASM `DATA_CMD_WRITE_V2 0x10dab` {addr lo, hi, handle, 3840, seq, 0, 0, 0}, token `0x80000000|period`; refill on `DATA_EVENT_WRITE_DONE_V2 0x10d99` (payload[3] = status); `SESSION_EVENT_RX_UNDERFLOW 0x10c17` (:969-995, :1113-1120). Teardown `STREAM_CMD_CLOSE 0x10bcd`, ADM `DEVICE_CLOSE_V5 0x10327`, `SHARED_MEM_UNMAP_REGIONS 0x10d94`, `AFE_PORT_CMD_DEVICE_STOP 0x100e6` (:1066-1083, :525-544).

(b) Mic (dev/umi_mic.c): AFE `REMOTE_LPASS_CORE_HW_VOTE_REQUEST 0x100f4` {block 3 or 4, client[8]} → `0x100f5` words[0] = handle; clocks `0x30c`, `0x30d` at 19.2 MHz; release `0x100f6` (:203-217, :305-378). Then ASM map (8 × 4 KiB) → port `0x201` `STREAM_CMD_OPEN_READ_V3 0x10db4` {mode 0, 0, topology `0x10c68`, fmt `0x10da5`, bits 16} → `STREAM_CMD_SET_ENCDEC_PARAM 0x10c10` {param `0x10da3`, size 28, 0, block 20 ms, ch 1, bits 16, 48000, signed, map {3}} → ADM open mode 2 (live recording), ep `0xb037`, ch 1, bits 16 → routing {matrix 1, session 2} → AFE port `0xb037` param `0x102b8` {1, 48000, bits 16, 0, ch 1, mask `1<<1`} → `DEVICE_START 0xb037` → `RUN_V2` → repeated `DATA_CMD_READ_V2 0x10dac` {addr lo, hi, handle, 1920, period}, token `0x40000000|period`; event `READ_DONE_V2 0x10d9a` {status, addr lo, hi, handle, size, offset} (:1181-1270, :1113-1162).

## Speaker path (CS35L41)
- I2C bit-banged on GPIO119 (SDA) / GPIO120 (SCL), taken from QUP SE3 per transaction; TLMM NORTH `0x0f900000`; 32-bit register address, data MSB first, ≤60 B per burst (hakios.speaker.c:1239-1244, :1252-1454). Amps at `0x40` (bottom/right) and `0x42` (top/left); one shared reset GPIO114 (:1241-1243, :2021-2024). Audio enters as MI2S2 on GPIO133 SCK, 135 WS, 137 SD1, mux 1/1/3 (hakios.sound.c:229-235).
- Files via `hakios_image_file("fw/cs35l41", ...)` (small image or `/fw`), never through the ADSP: `cs35l41-dsp1-spk-prot-revb2.wmfw` (both), tuning `cs35l41-dsp1-spk-prot-revb2.bin` (`0x40`) / `...-prot-RCV-revb2.bin` (`0x42`), calibration `cs35l41_cal.bin` / `cs35l41_cal_right.bin` = 4-byte LE resistance, valid 2000–30000 Ω, fallback 8392 (:1487-1493, :1765-1772).
- `.wmfw`: "WMFW", 40-byte header, bytes 10 and 11 must be 4 (HALO) and 3 (v3); records {u32 hdr (type 31:24, offset 23:0), u32 length, data}; type `0x10`→XM `0x03800000` (×5), `0x11`→YM `0x02000000` (×3), `0x12`→PM `0x02c00000` (×3), 5→`0x02800000` (×4), 6→`0x03400000` (×4), `0xf2/0xfe/0xff` text (:1457-1476, :1500-1534); every write read back (:1436-1454). Algorithm table at `0x02800000` must show fw id `0x400a4`, version `0x300`, one algorithm `0xcd` (:1535-1563). **[inferred]** This lock rejects Thor's `...-cali.wmfw` until re-derived. `.bin`: "WMDR", 16-byte header, records {u16 offset, u16 type, u32 algo id, ..., u32 length at +16, data at +20} relative to the algorithm's XM/YM base (:1564-1592).
- Power-up (:1974-2016): reset low 2 ms, high, 10 ms → DEVID `0x0 == 0x35a40`, REVID `0x4 == 0xb2` → board setup: OTP ready `0x1001c` bit 1, Rev B2 errata patch, OTP trims from `0x400..0x47c` (`umi_cs35l41_otp.h`, unlock `0x40=0x55,0xaa`, lock `0xcc,0x33`), boost `0x3810=0x2424`, `0x3814=0x7500`, `0x3808=0x40` (:1655-1683) → preload → `dsp_boot`: `0x6000=0x2004`, `0x2c0c`, `0x4808`, `0x4840`, `0x4820` = 1 (`0x40`) / `0x100` (`0x42`), PLL `0x1b`, HALO core at `0x02b80000+...`, calibration into CSPL XM (`xm+28` = R, `xm+36` = 1, `xm+40` = R+1), start `0x02bc1000=1`, mailbox test (`0x13020`=1, wait `0x10014` bit 21, state `0x13004`==1) (:1706-1800).
- Per playback (:1899-1936): mute `0x2024` bit 4, `0x4c00=0x32` (DAC from protection DSP), `0x6c04` = `18<<5`, test-window unlock + `0x2084=0x002f1aa0`, GLOBAL_EN `0x2014` bit 0, 2 ms, mailbox cmd 2, volume, unmute. Volume `0x6000` [13:3] = `((2048-att)&0x7ff)<<3 | 4` (1/8 dB, 2048 = 0 dB, max 816), 6 dB steps (umi_cs35l41_audio.h, :1941-1972). Health every 200 ms: `0x10010 & 0x800281c0`, CSPL `xm+12` (:1834-1859).
- PCM: 48 kHz stereo S16, 8 periods × 960 frames (20 ms, 3840 B, one page each) (hakios.sound.c:587-592). DSP address `0x10000000 | (0x1801&0xf)<<32`. SMMUv2 `0x15000000`: SMR ← stream `0x1801`, S2CR → context, stage-1 CBAR, 64-bit CBA2R, three 4 KB table pages, MAIR0 `0xf404ff44`, non-cacheable PTEs (:548-839); periods cleaned with `dc cvac` before `WRITE_V2` (:1313-1316). A 200 Hz high-pass and limiter still run in software (hakios.guard.c, :1667-1668).

## Microphone path
- WCD9385 on SoundWire 1.5.1 (TX slave `0x000d01170223`), Bolero TX macro `0x03220000`, VA macro `0x03370000`, SWR master `0x03230000`, LPASS pins 0–2 `0x033c0000`, codec reset GPIO32 (`0x0f520000`, mux 0) (umi_mic.c:384-388, :528-532).
- BOB is only observed read-only (SPMI EE0 observer `0x0e600000`); an RPMh `bobc1` vote (3312 mV) is made only if it is proven off (umi_mic_bob.h, dev/umi_rpmh.c:423-451).
- Order (:1585-1609): AFE votes and clocks → reset pulse → pins → TX/VA clocks (:539-560) → master 9.6 MHz (:584-617) → enumerate (:684-735) → codec init, MICBIAS 2750 mV (:850-888) → ADC1 only, gain 6 (:948-961) → DP1 → master port 2 (:917-930) → TX DEC1 48 kHz, HPF 150 Hz during settle, 0 dB, unmute after 200 ms (:982-1032). Stock uses ADC1+ADC4; this takes one (:14-16).
- No EC or noise reduction on media capture. Mono S16 48 kHz → `/dev/hakios-mic` (mode 0666): non-blocking `read()`, 16384-frame ring, reader held ≥40 ms behind (:1353-1433); up only while open; three failed recordings disable it for the boot (:1663-1667).

## User-space/IOKit interface
- No IOKit or IOAudio2. Kernel: `/dev/hakios-audio` (write-only, sink must not block, `ioctl HAKIOS_AUDIO_SET_VOLUME _IOW('r',1,{u32 below_eighths_dB, u32 muted})`, `below` clamped to 720) (drv/hakios.audio.c:213-300, sys/hakios.audio.h:19-38) and `/dev/hakios-mic`.
- `ul/audio_plugin.c` + `audio_plugin.plist` = `HakiosAudio.driver`, an **AudioServerPlugIn** (type UUID `443ABAB8-E7B3-491A-B985-BEB9187030DB`, factory `HakiosAudio_Create`, COM table :1028-1033), built as a `-bundle` (build.sh:300), at `/redwood/lib/HakiosAudio.driver`, symlinked into `/System/Library/Audio/Plug-Ins/HAL/` with Apple's HAL plug-ins omitted (build.sh:426-430, :860-861).
- Four devices named for VirtualAudio's iPhone X ('D22') tables (:16-32, :216-222, :233): "Speaker" (stereo out → `/dev/hakios-audio`, silent stereo in, 48 dB linear volume control), "Hawking" (silent mono in, required 'vhaw' companion), "Actuator" (mono out → `/dev/hakios-haptic`), "Codec" (mono in ← `/dev/hakios-mic`, data-source 'imic'). S16 48 kHz only (:304-317); clock = `mach_absolute_time()`, zero-timestamp period 16384 (:928-948); `DoIOOperation` WriteMix/ReadInput (:1001-1026). VirtualAudio sets the volume once to top and scales samples itself (:45-52).
- `inject_media.c` (libhakios.media.dylib in mediaserverd) only swallows the failing `BWAudioSourceNode` start so camera sessions work without audio (:251-266). Tests: `userland/rc.jobs.sound|mic|speakers|voicememos`, `rc.jobs.umi-speakers`.
- **[inferred]** With an iPad identity on iPadOS 18.7.10 VirtualAudio's device names may differ; the AudioServerPlugIn ABI is public and stable.

## Voice
- Trigger: QMI Voice CONVERSATION or IMS glue → `umi_voice_audio_start[_locked]` → worker (umi_voice_audio_control.inc:122-194), gated by the file `/var/db/hakios-voice/on` and text options `vsid` (`11c05000`), `tx-topology` (`10f70` none), `rx-topology` (`10f77`), `cvp-api` (2), `receiver-clock` (19200000), `volume-steps` (5) (VOICE:343-355).
- 128 KiB mailbox mapped into the modem's PCIe IOVA (MHI channel 80 `AUDIO_VOICE_0`, offload: no host ring) and ADSP IOVA `0x10020000`; `0x1333b` to MVM from port `0x0103` {u64 adsp, u64 pcie, u32 131072}; pinned until reboot (umi_voice_audio_apr.inc:86-94).
- Session (umi_voice_audio_session.inc:133-187): `0x11378` get CVD version → MVM create `0x110ff` (name[20]; handle = reply port) → CVS create `0x11140` → MVM dual control `0x11327` → take hardware from media (umi_voice_audio_route.inc:8-37: park feeder and watcher, close ASM/ADM, stop AFE and clock, `umi_voice_mic_take`) → CVP create V3 `0x13169` (CVD ≥ 22, else V2 `0x112bf`) {dir 2, tx `0xb037`, rx `0x1004` speaker / `0xb030` ear, topologies, cal-network `0x1135e`, mode `0x10f7c`, ec_ref `0xffff`} → formats (`0x1133d`, module `0x1316e`: `0x1328e/8f/90`, `0x13253/54`) → `0x13198` commit → `0x100c6` enable → `0x1123e` attach vocproc → CVP volume `0x112c2` → CVS mute `0x1138b` → MVM `0x11190` START_VOICE. Downlink is CVP → AFE directly, bypassing the media queue.
- Receiver: WCD9385 EAR via RX macro `0x03200000`, RX SWR `0x03210000` (slave `0x000d01170224`), AFE `0xb030`, clocks `0x30e/0x30f` (umi_voice_audio_receiver.inc).
- Teardown `0x11192` → `0x1123f` → `0x1003c` ×3 → media rebuilt (:97-132, route.inc:78-101). The iOS side (PhoneCall activation, cellular route, Apple private QMI AUDIO) is not implemented (VOICE:163-171).

## Dead ends
- Reading LPASS clock registers (`GCC_CFG_NOC_LPASS_CBCR`) from the AP crashes the kernel (hakios.adsp.c:13-14, hakios.speaker.c:1206-1210).
- No `lcx/lmx` vote: the DSP leaves "SFR Init: wdog or kernel error suspected." (hakios.adsp.c:784-789). Wrong SMP2P item order: it never says "up" (:322-325). Restart after an unacknowledged stop reset the phone (:62-64). 32-bit GLINK lengths livelocked the link thread (:2201-2204).
- UMI: GPIO32 DT "func2" rejected, mux 0 needed (umi_mic.c:405-407); Redwood's `FREQ_MCLK` readback and FIFO count field not trusted (:552-553, :662-663); +12 dB guard gain pinned the limiter (hakios.sound.c:1717-1719); preempted bit-bang reads NACK spuriously, retry transport only (hakios.speaker.c:1818-1819); HALO heartbeat can freeze with GLOBAL_EN 0 (:1798).
- Voice: GSM/CSFB dead end at the test location (VOICE:37, :237); Apple private QMI AUDIO `0xe1/0x2f` rejected `0x5e`, `mediactl` has no backend (VOICE:44, :65); `hakios_adsp_apr()` hid the reply port, so voice got its own sender (VOICE:167); channel 80 gets no host ring (VOICE:251-255); mailbox never freed (VOICE:257); ACDB = index tables, no EC by default (VOICE:357); 160 ms media queue unusable for speech (VOICE:97).
- Camera video has no audio (inject_media.c:251-266). `MIC-umi.md` is referenced but absent; `CHANGELOG.md` and `STATUSBAR-umi.md` say nothing on audio.
